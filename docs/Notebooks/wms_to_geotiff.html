Export GeoTIFF from WMS

Now let’s export a GeoTIFF from the WMS service. We’ll specify: - url: The WMS service URL - layers: The layer(s) to request - bbox: Bounding box as [minx, miny, maxx, maxy] in EPSG:4326 - output: The output file path - scale: The resolution in degrees per pixel (for EPSG:4326)

Example 1: Export using scale parameter

def wms_2_geotif(url, layers, bbox, output):
    # You can provide bbox in EPSG:4326 and output in EPSG:3857
    # The function will automatically transform the coordinates
    common.wms_to_geotiff(
        url=url,
        layers=layers,
        output=output,
        scale=0.5,  # 1 meters per pixel for projected CRS
        bbox_crs="EPSG:4326",  # Input bbox CRS (default)
        output_crs="EPSG:3857",  # Output CRS
        quiet=True,
        )
output = "Salvador_ilha_mare.tif"
bbox = [-38.5428, -12.8036, -38.5256, -12.7944 ]
